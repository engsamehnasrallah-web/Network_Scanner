# Network_Scanner

## Overview

Simple Python-based TCP Port Scanner.

## Features

- Scan Single Host
- Scan Custom Port Range
- Detect Open Ports
- Service Identification
- Execution time statistics

## Technologies

- Python
- Socket Programming

## Usage

~~~bash
python scanner.py
~~~

## Example
Scan localhost from port 1 to 1000
